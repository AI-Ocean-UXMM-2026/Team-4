# Shaysett: earlier Kyaw Myanmar showcases

These earlier demonstration workbooks are retained for comparison and regression work. For the current DuoMuse example, start with the [examples guide](../README.md).

| Workbook | Description |
| --- | --- |
| [Wholesale showcase](Shaysett_Showcase_Wholesale_Kyaw_Myanmar.xlsx) | Earlier Kyaw Myanmar wholesale/distribution dataset. |
| [Baseline showcase](shaysett-showcase-kyaw-myanmar.xlsx) | Earlier baseline dataset with partial loan terms. |

The filenames use the current Shaysett name; workbook contents and record IDs are preserved. Any older branding inside these historical workbooks describes their original context. Do not treat their business identifiers as sign-in credentials or ownership grants. Import only into a test workspace you are authorized to use.

Feature output depends on the imported facts and the current implementation. These fixtures do not guarantee that every module has sufficient inputs or that an external AI provider is configured. Demo findings can also change with the reporting date.

Optional synthetic-demo labels use the server-only `AI_SYNTHETIC_DEMO_BUSINESS_ID` and `AI_SYNTHETIC_DEMO_IMPORT_SHA256` settings. If used, set them to the actual test workspace ID and exact workbook hash; never copy an unrelated workspace ID.
