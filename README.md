# Cashflow Compass Companion

I want a prototype for an app called BizFlow which can be used by both SME having credit and SME without credit. for dashboard, i want to show cashflow within a month so that user can check up or down tracking. for features, feature1: can be used by both credit or no-credit sme, ai will analyzed cash in, cash out, stock amount, remaining debt, remaining total cash and predict future financing and tell how user should manage to increase profit, reduce cost, reduce debt, how much loan user should borrow per month/year. feature2: for no-credit users, give plans on how to survive without credit according to the data they put in the feature1. feature3: giving recommendations and steps on necessary things to do for applying credit like business registration, bank statement, etc that are required to apply credit like a checklist. (according to this idea, produce a prototype without backend, api. i just want a prototype so that my teammates can see through the features clearly)
