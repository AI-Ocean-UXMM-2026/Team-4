# ရှေ့ဆက် — ကော်ဖီဆိုင် စကားပြောဇာတ်ညွှန်း

စုစုပေါင်း သတ်မှတ်ချိန် — ၄ မိနစ်။ သီရိနှင့်ထက် နှစ်ယောက်တင်ဆက်ရန်။

ကွင်းစကွင်းပိတ်အတွင်းရှိ စာများသည် သရုပ်ဆောင်နှင့် screen ပြောင်းရန် ညွှန်ကြားချက်များဖြစ်ပြီး အသံထွက်ဖတ်ရန် မဟုတ်ပါ။ အချိန်ကွက်များသည် rehearsal အတွက် ရည်မှန်းချက်များဖြစ်သည်။ Demo recording များကို ကြိုတည်းဖြတ်ထားပြီး loading နှင့် click စောင့်ချိန်များကို ဖြတ်ထားပါ။
